# 视觉范式基线：《何以江南》

状态：Draft（首份真实样张范式）
日期：2026-06-18
来源样张：`～何以江南/indesign排版/何以江南03F.pdf`（24 页样章，InDesign 排版导出）

本文把《何以江南》样章的视觉设计**拆解成可被 layoutD 复用的结构化范式**，作为软件"导入样式基线 → 灌版 → 人工微调"流程里的第一份真实参照。它**不是**要让引擎复刻每一页画面，而是抽取出网格、字阶、颜色 token、组件样式与图片处理规则。

> 数据标注约定：**【实测】**= 从渲染图测得；**【估算】**= 从版面比例目测推断，需在拿到原始 InDesign/Figma 文件后校准。

---

## 0. 一句话定位

《何以江南》是一本**奢华文艺向的图文科普书**（江苏凤凰科学技术出版社），设计密度远高于普通科普：满版照片、双色调着色、渐变美术字、扇面/八边形图框、篆刻印章、竖排引文、中英双语。它的版面必须拆成两层看：

- **结构层（可参数化、可复用）** → layoutD 能接管：网格、字阶、颜色 token、图注/页眉/页码、正文灌版与一致性。
- **美术层（逐页定制的艺术件）** → 作为**成品图/装饰资产置入**，引擎不解析、不重排。

---

## 1. 两层模型

| 层 | 内容 | layoutD 处理方式 |
|---|---|---|
| 结构层 | 开本/网格、颜色 token、文字层级、图注/页眉/页码、正文流、参考书目 | 抽成 StyleLibrary + PageSetup + 模板，确定性灌版 |
| 美术层 | 封面美术字、满版照片整页、扇面/八边形图框、篆刻印章、装饰底纹、博物插画拼版、竖排书法 | 作为 Asset / 特殊固定页置入，不进重排引擎 |

这条划分与 layoutD 既定原则一致：人工只在结构化模型上微调，不引入自由几何；图表等成品图作为素材摆放（见 [layoutd-prd.md](layoutd-prd.md) §5.2）。

---

## 2. 开本与网格（→ PageSetup）

| 项 | 值 | 说明 |
|---|---|---|
| 单页开本 | **185 × 260 mm**【实测】 | 跨页渲染 1602×1126px@110dpi → 单页 ≈ 7.28×10.24in ≈ 185×260mm，**正好是 layoutD 默认开本** |
| 装订 | 对页（facing pages），按跨页设计 | 章节开场、满版图常跨页 |
| 正文栏 | 每页约 2 栏、跨页约 4 栏，两端对齐【估算】 | 正文为多栏 justified 中文流 |
| 页边距 | 偏宽，留白充裕【估算】 | 文艺向排版，外白/天地较大 |
| 基线网格 | 存在但无法从图测出【估算】 | 需原文件校准；Figma 不表达基线，导入时由 layoutD 补默认 |
| 页眉 | 上方：左=书名「何以江南」、右=章节名；细线分隔【实测】 | 对应 layoutD 的 `runningHeader` 语义 frame |
| 页码 | 下方外角，阿拉伯数字（如 `62 / 63`）【实测】 | folio，layoutD 待加 |

## 3. 颜色系统（→ color tokens）

| token | 用途 | 备注 |
|---|---|---|
| 主题色·绿（青绿系） | 水/自然类章节的强调色、引文、图注、图片双色调 | 见 p.5 环太湖、p.16 生态拼版、p.20 |
| 主题色·蓝 | 都府/山类章节的强调色、书脊渐变 | 见 p.6/8/10 |
| 渐变（绿↔蓝） | 封面美术字、书脊竖向渐变带 | 美术层，作整图 |
| 墨黑/深灰 | 正文、标题 | 正文用色克制 |
| 纸白/浅底纹 | 背景、装饰底纹（山水纹、水波纹） | 章节页左幅满铺浅纹 |

**关键范式：颜色按章节主题切换（绿/蓝）**，且图片常被**双色调（duotone）着色到主题色**。→ layoutD 的 token 系统需要"**主题色组 / 多模式**"概念（一组 token 随章节切换），这与 Figma Variables 的 modes 天然对应。

> 能力缺口：**图片 duotone 着色**目前 layoutD 没有，需评估是作为图片预处理（设计端出图）还是软件渲染特性。

## 4. 文字层级（→ StyleLibrary / ParagraphStyle）

| 样式 | 出现位置 | 特征【实测/估算】 |
|---|---|---|
| 章节类目签 | 章节/小节开场，如 `都府 / 山` | 小字、主题色、带分隔斜杠 |
| 章节主标题 | 如 `紫金山`、`环太湖` | 大号、可用美术字/特殊字体 |
| 副标题 | 如 `钟灵毓秀，神烈之山` | 中号、灰或主题色 |
| 正文（中文） | 多栏两端对齐 | 宋体系，正文主力 |
| 正文（英文译文） | 与中文并置/分段 | 西文字体，**全书中英双语** |
| 图注 | 图旁，常**竖排**、主题色 | 小字 |
| 引文/诗 | 正文左侧**竖排**书法风 | 绿/蓝色、竖排 |
| 数据签 | 信息图顶部，如 `年均降水量 1000–1400` | 小字 + 上标单位 |
| 参考书目 | 后记页，编号文献 `[1][2]…` | 学术列表样式 |
| 页眉 / 页码 | 见 §2 | 细字 |

> 能力缺口：**(a) 竖排（直排）**——引文/诗/部分图注是竖排；PRD 现把竖排列为 Phase 3 后续，但对江南/古典题材是刚需。**(b) 中英双语并置**——标题锁版与正文都是中英对照，是一类段落关系，当前模型未专门处理。

---

## 5. 组件与版式模板（→ components / LayoutTemplate）

| 组件/模板 | 描述 | layoutD 落点 |
|---|---|---|
| 小节开场锁版 | 类目签 + 主标题 + 副标题 + 扇面图 + 竖排说明 + 印章 | ChapterLayoutTemplate（装饰件作资产） |
| 正文跨页模板 | 左竖排引文 + 右上图带注 + 双语正文流 | PageLayoutTemplate |
| 图 + 图注 | 矩形/扇面/八边形图框 + 竖排或横排图注 | 图片 frame + caption（非矩形 mask 为新能力） |
| 竖排引文块 | 主题色竖排书法 | 新组件类型（依赖竖排能力） |
| 数据签条 | 信息图顶部一排指标 | 信息图整体作成品图；数据签若要可编辑则为新组件 |
| 参考书目列表 | 编号文献 + 渐变描边页 | "书目/后记"模板 |
| 满版图版 | 整页/跨页满血照片，无文字 | 特殊固定页（placed asset） |

---

## 6. 图片处理范式（→ Asset 角色）

| 角色 | 例 | 说明 |
|---|---|---|
| 满版图版 | p.3 卫星图、p.23 武当山 | 出血满版，纯图，不重排 |
| 双色调主题图 | p.5 环太湖、p.20 | 着主题色、可叠文字/路线图 |
| 扇面/八边形图框 | p.6/8/10 | 传统装饰裁切 mask（**非矩形图框=新能力**） |
| 正文插图 | p.12 顶部小图 | 矩形 + 图注，参与版面 |
| 博物插画拼版 | p.16 鸟/鱼/植物手绘 | 手绘插画叠生态场景 + 引线图注；多为成品拼图 |

> 能力缺口：**非矩形图框 mask（扇面/八边形）**。建议作为图片"装饰边框/蒙版"资产或固定页处理，不要求引擎参数化生成。

---

## 7. 美术层清单（明确排除出重排引擎）

以下元素**逐页定制**，按成品图/装饰资产置入，引擎不解析：

- 封面**渐变美术字**（`何以江南`，逐字渐变描边）
- **满版装饰底纹**（山水纹、水波纹，章节页左幅满铺）
- **篆刻印章** ornament（竖向反复出现）
- **扇面 / 八边形图框 mask**
- **书脊竖向渐变带**
- **竖排书法引文/诗**（若软件不做竖排，则整块作图）

## 8. 与 layoutD 现状的差距小结

| 能力 | 现状 | 缺口 |
|---|---|---|
| 185×260 开本 / 对页 / 多栏 | ✅ 已支持 | — |
| 颜色 token | 🟡 有 | 缺"主题色组/多模式切换" |
| 文字层级 | 🟡 有骨架 | 需扩到本书的全套层级 |
| 页眉 | ✅ 语义 frame | 页码 folio 待加 |
| 章节/页面模板 | ✅ 有目录 | 需按本书锁版扩充 |
| 竖排文字 | ❌ 无 | 江南题材刚需，需提前 |
| 中英双语并置 | ❌ 无 | 段落关系新类型 |
| 图片 duotone 着色 | ❌ 无 | 评估软件渲染 vs 设计端出图 |
| 非矩形图框 mask | ❌ 无 | 作装饰资产处理 |

---

## 9. 结论

- **"结构层"可提取、可复用，价值高**：网格、字阶、颜色 token、图注/页眉/页码、正文灌版与一致性，layoutD 能接管 → 这就是"灌版"。
- **"美术层"按成品资产处理**：封面、满版美术、扇面印章、装饰底纹、博物拼版，由设计端（Figma/AI/绘图）产出后置入。
- 这本书**美术层占比偏高**，因此对它的诚实定位是：**软件接管正文与一致性，美术由设计师供图**。layoutD 更适合"结构层规整、美术层适中"的科普书；对重美术的书，软件做"骨架 + 灌版 + 检查"，不做"美术生成"。
- 本书额外暴露两个**应提前的能力**：竖排、中英双语并置。
